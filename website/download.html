STEP 1: GET THE TOOLS

You need V 0.5.2, SDL3 and just. On macOS:

brew install vlang sdl3 just

Tried on macOS arm64. The headless runner links without SDL and should build wherever V does; nobody has tried yet. Linux and Windows reports go in the issue tracker.

STEP 2: GET THE SOURCE

git clone https://github.com/HelgeSverre/jaguar
cd jaguar

STEP 3: PLAY

just run demos/hero.jag        # optimized build, then play
just run                       # empty window: drop an image on it
just run path/to/game.j64      # your own cartridge dump

WHERE ARE THE ROMS?

Not here. Not in the repo. Not on request. Bring your own, or play the homebrew built from source.

WHERE IS THE BOOT ROM?

Also not here, and not needed: everything starts by direct boot with the video timing the boot ROM would have left behind.

just on its own lists every recipe.

WHERE THINGS GO

  • Saves land in your data directory, keyed by the content of the image. Renaming a file keeps its save.
  • Settings live in vjag/config.toml under your configuration directory (~/Library/Application Support on macOS). shell = false turns the console shell off for good; --no-shell for one run.
