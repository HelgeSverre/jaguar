THE LADDER

LEVELWHAT IS TESTED
68000The full SingleStepTests corpus, as above.
DevicesThe object processor, blitter, RISC cores, EEPROM, controller matrix and timers have unit tests that check exact memory and register results.
Whole machineSmall hand-assembled programs boot through the real loader, run on the 68000, hand work to the GPU and publish a result word.
LoaderSynthetic fixtures for every format and every way a file can be truncated or lie about itself.
jagkitEvery instruction form the assemblers accept is read back through the emulator's disassemblers. Every demo is built, booted as NTSC and as PAL, and played by its test.
jaggameA differential fuzzer runs random programs in the interpreter and on the emulated 68000; they must agree.
RobotsGHOSTGRID's robot plans an unseen route through all ten missions. Jaguar Hero's robot plays the finale with every note perfect. Their runs are kept as press files and replayed on a fresh machine.
A second emulatorjust crosscheck runs the demos in Virtual Jaguar and leaves pictures to compare. It fetches and builds that emulator, so it is not part of just test.
